# 📚 StudyTrack Web

## 📖 Proje Hakkında

StudyTrack Web, öğrencilerin çalışma süreçlerini daha verimli planlayabilmeleri amacıyla geliştirilen web tabanlı bir Pomodoro ve günlük çalışma planlayıcısıdır.

Kullanıcılar çalışma planlarını oluşturabilir, Pomodoro tekniği ile odaklanma sürelerini takip edebilir ve günlük çalışma hedeflerini belirleyebilir.

---

## 🚀 Özellikler

* ⏱️ Pomodoro Sayacı
* ☕ Kısa Mola (Short Break)
* 🌙 Uzun Mola (Long Break)
* 📝 Günlük Çalışma Planlayıcısı
* 🎯 Günlük Hedef Belirleme
* 📊 Çalışma İstatistikleri
* 💾 Verilerin Local Storage ile kaydedilmesi

---

## 🛠️ Kullanılan Teknolojiler

* HTML5
* CSS3
* JavaScript
* Local Storage API

---

## 🎯 Projenin Amacı

Bu proje, öğrencilerin ders çalışma alışkanlıklarını geliştirmelerine yardımcı olmak amacıyla hazırlanmıştır.

Uygulama sayesinde kullanıcılar;

* Günlük çalışma planı oluşturabilir.
* Pomodoro tekniği ile odaklanma süresini yönetebilir.
* Günlük çalışma hedefi belirleyebilir.
* Çalışma istatistiklerini takip edebilir.

---

## 🔄 Geliştirilmesi Planlanan Özellikler

* Haftalık ve aylık çalışma raporları
* Responsive (mobil uyumlu) tasarım
* Bildirim sistemi
* Ses efektleri
* Açık/Koyu tema desteği
* Görev tamamlama sistemi
* Çalışma grafikleri
